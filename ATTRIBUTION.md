# Attribution

## UltraWhisper is based on Handy

UltraWhisper is a fork of [Handy](https://github.com/cjpais/Handy), an excellent open-source speech-to-text application created by [CJ Pais](https://github.com/cjpais).

### Original Project
- **Project**: Handy
- **Author**: CJ Pais (@cjpais)
- **Repository**: https://github.com/cjpais/Handy
- **License**: MIT License

### What We've Built On

Handy provided the solid foundation for UltraWhisper, including:
- Robust audio capture with Voice Activity Detection
- Whisper model integration for transcription
- Cross-platform Tauri architecture
- Global keyboard shortcuts system
- Recording history management

### Our Additions

UltraWhisper extends Handy with:
- Workflow-based transcription routing
- File output for transcriptions (beyond clipboard)
- Folder watching for batch processing
- Extended integration options (Obsidian, webhooks, etc.)
- Additional workflow automation features
